# Miyapuram Vinay — Mechanical Design Portfolio

Black, minimal, editorial-style engineering portfolio inspired by the supplied reference video.

## Publish with GitHub Pages
Upload `index.html`, `styles.css`, `script.js`, and the complete `assets` folder into the root of `vinaymiyapuram.github.io`. Keep filenames and capitalization unchanged. Commit the upload, then wait for GitHub Pages to publish.

## Assets used
Profile, go-kart, Fusion 360, ANSYS, APPC certificate, resume and two project videos are included under `assets/`.

## Notes
The Hydrogen-assisted go-kart and solar-assisted EV charging station are presented as concept/student projects. The motor monitoring system is described as an Arduino prototype. Placeholder visuals are used for motor monitoring and EV hackathon sections because dedicated images were not supplied.
